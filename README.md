# Student Performance Analyzer

## Project Overview
This is my first data analysis portfolio project using Python and pandas.

The project uses sample student marks to analyze academic performance.

## Objectives
- Calculate the average marks of each student.
- Compare performance across subjects.
- Identify students who pass or fail using a practice threshold.
- Summarize the results using tables and visualizations.

## Tools
- Python
- pandas
- Jupyter Notebook
- GitHub

## Dataset
This project initially uses fictional sample data created for practice. It does not contain real student records.
